# Bioinformatics-spiecies-model-exersize 
A mathematical model of 3 species will be described. It represents a tree-level food chain describing the following species: plants, hares and lynxes. The plants are the producers, the hares are the primary consumers and the lynxes act as the predators. To model the populations over 200 months, a set of equations has been provided in a matlab function file. 3 scenarios will be described in this assignment. In scenario one, the system should show a stable oscillation with a period of 70 months. This will allow us to predict how these populations interact in a simplified system over long periods of time. In scenario 2, the lynxes should go extinct after a year and the other populations should stabilize after 120 months. It is crucial to be able to model extinctions, since it provides understanding on how species in nature rely on each other to survive and how the destruction of biodiversity can disturb population behaviors. Lastly, the system should show chaotic behaviour, making long-term prediction and stable oscillation impossible. 
The system of equations represents how the populations change over time. The first equation will represent the plant population, the second the hares population and the third the lynxes population. These are present in the function file plants_hare_lynx.m. There are multiple parameters a1 is the maximum consumption rate by hares on plants, b1 is the saturation constant for the consumption of plant, a2 is the maximum lynx predation rate on hares, b2 is the hares' saturation for lynxes, d1 capita death rate of hares and finally d2 is the capita death rate of the lynxes.
For this assignment, we will use MATLAB version r2025b.
